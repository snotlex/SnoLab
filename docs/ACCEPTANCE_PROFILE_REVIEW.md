# إجراء مراجعة ملف القبول

1. ينشئ المختبر ملفًا بحالة `Draft` مرتبطًا بالمشروع والنطاق والاختبار والمعيار ووثيقة المصدر.
2. يراجع المستخدم المخول بالاعتماد الملف من بوابة المختبر.
3. يتحقق النظام من هوية المراجع، وحالة الملف، والمعيار، والوحدة، ووثيقة المصدر، واكتمال الحد حسب نوع العملية.
4. عند نجاح التحقق تتحول الحالة إلى `Active`، ويسجل النظام `reviewedBy` و`reviewedAt` و`reviewNote`.
5. عند فشل التحقق يبقى الملف `Draft` وتظهر رسالة تمنع التفعيل.

صلاحية زر المراجعة مرتبطة بصلاحية `approve-test`. لا يتم تفعيل ملف مكتمل جزئيًا ولا يتم اختراع حدود قبول.
