# تنفيذ المرحلة 3 — حوكمة الهوية مع الحفاظ على local-first

## النطاق المنفذ

تم تنفيذ الأساس الآمن والقابل للعكس للمرحلة 3 دون نقل مصدر الحقيقة الهندسي إلى قاعدة بيانات:

1. **هوية وملكية اختيارية** داخل `metadata` عبر `ownerId` و`teamId`.
2. **هوية تشغيلية اختيارية** (`subject`, `teamId`, `roles`) لا تحتوي كلمات مرور أو رموز وصول.
3. **سجل تدقيق مستقل** للعمليات الحساسة: `upload`, `download`, `share`, `export`, `import`.
4. **نسخ immutable لملف `.snlab`** تتضمن `versionId` و`schemaVersion` و`contentHash` و`byteLength`.
5. **غلاف رفع قابل للتحقق** يرفض المحتوى المعدّل قبل القبول عبر SHA-256.

## قرار معماري

يبقى ملف `.snlab` مصدر الحقيقة. هذه الإضافة لا تنشئ مزامنة تلقائية ولا تنسخ المشروع إلى قاعدة بيانات. لذلك يمكن للمستخدم مواصلة العمل دون حساب أو اتصال، بينما تستطيع طبقة هوية مستقبلية إضافة المالك والفريق عند توفرها.

> لا يُسمح باستخدام هذه العقود وحدها لإثبات صلاحيات الوصول؛ يجب أن تأتي قرارات التفويض من طبقة هوية/خادم موثوق عند بناء SaaS.
