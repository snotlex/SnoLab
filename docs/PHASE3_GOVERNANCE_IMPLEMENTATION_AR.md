# تنفيذ المرحلة 3 — حوكمة الهوية مع الحفاظ على local-first

## النطاق المنفذ

تم تنفيذ الأساس الآمن والقابل للعكس للمرحلة 3 دون نقل مصدر الحقيقة الهندسي إلى قاعدة بيانات:

1. **هوية وملكية اختيارية** داخل `metadata` عبر `ownerId` و`teamId`.
2. **هوية تشغيلية اختيارية** (`subject`, `teamId`, `roles`) لا تحتوي كلمات مرور أو رموز وصول.
3. **سجل تدقيق مستقل قابل للتصدير** للعمليات الحساسة: `upload`, `download`, `share`, `export`, `import`، بصيغتي JSON وCSV الآمنة.
4. **نسخ immutable لملف `.snlab`** تتضمن `versionId` و`schemaVersion` و`contentHash` و`byteLength`.
5. **غلاف رفع قابل للتحقق** يرفض المحتوى المعدّل قبل القبول عبر SHA-256.

## قرار معماري

يبقى ملف `.snlab` مصدر الحقيقة. هذه الإضافة لا تنشئ مزامنة تلقائية ولا تنسخ المشروع إلى قاعدة بيانات. لذلك يمكن للمستخدم مواصلة العمل دون حساب أو اتصال، بينما تستطيع طبقة هوية مستقبلية إضافة المالك والفريق عند توفرها.

> لا يُسمح باستخدام هذه العقود وحدها لإثبات صلاحيات الوصول؛ يجب أن تأتي قرارات التفويض من طبقة هوية/خادم موثوق عند بناء SaaS.

## ما لم يُنفذ بعد

- ربط OAuth فعلي من `snotlex-manus`.
- خادم رفع أو تخزين سحابي.
- نموذج tenancy نهائي وصلاحيات الفريق.
- مشاركة أو تحرير متزامن.
- تشفير النسخ الاحتياطية وسياسات الاحتفاظ والحذف.

يجب تنفيذ هذه البنود بعد اعتماد نموذج الملكية والتعارضات وسجل التدقيق القابل للتصدير، وليس قبل ذلك.

## قائمة إغلاق المرحلة 3

اعتُبرت المرحلة 3 مكتملة ضمن نطاق local-first بعد تنفيذ البنود التالية:

- [x] نسخ خلطات immutable مع hash وrevision ومقارنة إصدارات داخل الواجهة.
- [x] هوية وملكية اختيارية دون فرض حساب أو اتصال.
- [x] سجل تدقيق مستقل للعمليات الحساسة.
- [x] تصدير سجل التدقيق بصيغتي JSON وCSV مع تحييد قيم الصيغ.
- [x] مصفوفة أدوار وصلاحيات وفصل واجب الإنشاء عن الاعتماد.
- [x] عقود تقارير قابلة للتدقيق تتضمن verification/approval/integrity metadata.
- [x] اختبارات وصولية آلية للحقول الرقمية ومسار تصحيح الأخطاء.
- [x] حارس أداء في Playwright موصول بأمر `npm run test:performance` وGitHub Actions.

أما OAuth الفعلي، والتخزين السحابي، وtenancy، والتحرير المتزامن، والتشفير وسياسات الاحتفاظ، فهي **مرحلة SaaS لاحقة** وليست شرطًا لإغلاق حوكمة local-first الحالية.
