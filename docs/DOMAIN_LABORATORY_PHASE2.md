# الدفعة الثانية — ملفات القبول وسياق المشروع

أضيف `laboratoryAcceptanceProfiles.ts` لتسجيل ملف قبول مرتبط بالمشروع والنطاق وتعريف الاختبار والوثيقة المصدرية. يتم اختيار الملف الأكثر تخصصًا الذي يطابق سياق الاختبار، مع منع المطابقة عبر نطاق أو اختبار مختلف.

الملف النشط لا يصبح صالحًا إلا بوجود معيار، وحدة، وثيقة مصدر، وبنية حد مكتملة حسب نوع العملية. عند غياب ملف مطابق أو عدم اكتماله تبقى النتيجة `NEEDS_REVIEW`.

يحتفظ `LaboratoryTestRun` الآن بمعرف ملف القبول ولقطة قرار القبول، بما يتيح ربط النتيجة بالتاريخ والسبب والوثيقة بدل إعادة التقييم بأثر رجعي من إعدادات متغيرة.

لم تُضف حدود رقمية فعلية؛ تلك القيم يجب أن تأتي من مواصفات المشروع أو سجل المختبر المعتمد.
